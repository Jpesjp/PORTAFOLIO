Proyecto 2: WayTure

Aplicación web para planificación, gestión y rastreo de viajes, con autenticación, panel de usuario, panel administrativo y almacenamiento de datos en Firebase.

Tecnologías: HTML5, CSS3, JavaScript modular, Firebase Authentication, Cloud Firestore, Google Maps Embed y localStorage.
