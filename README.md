# Portafolio Profesional

Este proyecto contiene un portafolio web básico realizado con HTML, CSS y JavaScript.

## Estructura

- `index.html`: página principal.
- `css/estilos.css`: estilos del sitio.
- `js/script.js`: funciones de audio y animaciones.
- `img/`: imágenes o capturas del portafolio.
- `audio/`: audio de presentación personal.


## Tecnologías utilizadas

HTML5, CSS3 y JavaScript.
