# Portafolio Profesional

Este proyecto contiene un portafolio web básico realizado con HTML, CSS y JavaScript.

## Estructura

- `index.html`: página principal.
- `css/estilos.css`: estilos del sitio.
- `js/script.js`: funciones de audio y animaciones.
- `img/`: imágenes o capturas del portafolio.
- `audio/`: audio de presentación personal.

## Instrucciones

1. Cambia `Tu Nombre Completo` por tu nombre real.
2. Actualiza email, teléfono y enlace de GitHub.
3. Reemplaza las imágenes de ejemplo por tus capturas reales.
4. Agrega tu audio en `audio/presentacion.mp3`.
5. Sube la carpeta a GitHub.

## Tecnologías utilizadas

HTML5, CSS3 y JavaScript.
